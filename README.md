# Твоя звезда

Личный статический сайт для Амалечки. Собран без сборщика: `index.html`, `style.css`, `content.js`, `app.js`.

## Фотографии

- В репозитории находятся только закодированные фото-пакеты в `assets/media.js`.
- Исходные файлы в `assets/photos/` и `.private-photos/` не коммитятся.
- Сайт показывает фото через blob-URL, без прямого `assets/photos/...` в HTML.
- На изображения отключены обычный ПКМ, перетаскивание и выделение.

Важно: GitHub Pages — публичный сайт. Просмотр невозможен без доступа к странице, а скачивание исходников настолько защищено, насколько это возможно для статического сайта. Через DevTools, сетевую вкладку или скриншот страницу всё равно можно сохранить. Для такой защиты это единственное честное поведение браузера.

## Локальная проверка

Открыть `index.html` или поднять локальный сервер:

```powershell
python -m http.server 4173
```

Затем открыть `http://localhost:4173`.

## Обновление фото

Положить новые файлы в `.private-photos/` и пересобрать медиа-пакет:

```powershell
node tools/embed-photo-assets.mjs
```
